# Archived SQL

Everything below this directory is historical reference, not an execution
queue.

- `applied/`: component files consolidated into the verified baseline.
- `proposals/`: never-applied ideas requiring a new reviewed migration.
- `one_time/`: completed staging fixes and troubleshooting SQL.
- `experiments/`: obsolete prototypes.

Do not run archived files on staging or production. If an old idea becomes
active, create a new timestamped migration under `supabase/migrations/`.
